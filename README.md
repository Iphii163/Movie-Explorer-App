# 🎬 Movie Explorer

A responsive movie discovery web application built with **HTML, CSS, and JavaScript** that allows users to browse, search, and explore movies and TV series using the **TMDB API**. The application features a modern hero section, category-based browsing, favorites management, and a fully responsive interface.

## ✨ Features

- Browse trending movies and TV series
- Search movies and TV shows by title
- Browse content by category
- Add and remove movies from Favorites
- Pagination for seamless browsing
- Modern Hero Section with featured content
- Fully responsive design for desktop, tablet, and mobile devices
- Dynamic content rendering using the TMDB API

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- TMDB API
- Fetch API
- DOM Manipulation
